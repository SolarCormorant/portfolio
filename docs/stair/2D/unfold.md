## Unfolded Glass

- An unfolded 2D drawing of the glass panels is automatically generated from the 3D model, reflecting all design decisions.

- Parameters such as the number of items per row and the gap between drawings are user-adjustable, allowing for clean, production-ready documentation tailored to layout and sheet preferences.
